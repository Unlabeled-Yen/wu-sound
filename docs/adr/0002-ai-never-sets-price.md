# 報價系統:AI 只選品項與數量,絕不決定價格

`lib/ai-quote.ts` 的 `SuggestedLine` 型別完全沒有價格欄位(只有 `catalog_name` / `qty` / `spec` / `reason`),prompt 也明講「你絕對不決定價格,也不需要提到任何金額;價格由系統另外處理」。金額一律由 `lib/quote-calc.ts` 的規則引擎,依 `catalog_items` 表裡老闆自己填的進價/售價計算,AI 完全碰不到這條路徑。

**背景**:老闆是唯一改價權人,價格依案件規模與市價浮動,不能讓 AI 用猜的。這條界線是刻意在型別層級擋死,不是靠 prompt 自律——即使 AI 想亂講金額,回傳的 JSON 結構也放不下這個欄位。

**如果要改**:未來若真的要做「AI 建議報價區間」這類功能,請開一個新的、明確標示為「AI 估算、僅供參考」的獨立欄位或流程,不要把價格塞進 `SuggestedLine`,避免跟目前「AI 選品項/系統定價格」這條清楚的責任分界混在一起。
