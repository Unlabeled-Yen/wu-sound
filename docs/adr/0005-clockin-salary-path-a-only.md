# 打卡↔薪資結算只做 A 路(工時聚合+老闆手填薪水),不做 B 路(完整薪資自動化)

系統會把員工打卡紀錄聚合成工時總數,但薪資金額仍由老闆手動填入,系統不自動算薪水。

**背景**:2026-07-15 老闆提出「薪資結算要與員工打卡連結、當月零用金一併結算」的新需求。技術上資料都具備,完全可以做到自動算薪(B 路:時薪結構 × 工時 × 加班倍率等),但團隊明確選擇只做 A 路,理由是老闆從未在 intake 提供薪資結構(時薪/月薪/日薪、加班規則、獎金扣款等),強行用預設值猜測會讓系統自己做了老闆沒有授權的決策,違反「缺資料要 loud、不能靜默假設」的原則。詳見 `docs/open-questions.md`。

**何時可以做 B 路**:老闆主動提供每人薪資結構、加班規則、其他薪資成分後。在那之前,自動算薪是明確不做的功能,不是還沒做完。
