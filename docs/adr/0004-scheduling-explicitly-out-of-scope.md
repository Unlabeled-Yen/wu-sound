# 排程功能刻意不做

系統沒有排班/排程模組,這是刻意排除,不是遺漏。

**背景**:2026-07-10 訪談與後續規劃階段,老闆從未主動提出排程需求,團隊當時明確拍板:「排程降為後段候補,除非老闆明確提出否則不做」。之後在 2026-07-14 checkpoint 再次確認維持不做。

**為什麼值得記錄**:一個音響工程公司的工作系統「沒有排程功能」乍看會讓人覺得是漏做了,尤其其他模組(打卡、零用金、工作記錄、設備、報價、內外帳)都已經很完整。如果沒有這篇記錄,未來的工程師(或 AI agent)很可能會主動「補上」這個看起來明顯缺少的功能,但這其實是刻意的範圍決定,不是待辦事項。

**何時可以重新考慮**:老闆自己主動提出排程需求時。在那之前不要自己加。
