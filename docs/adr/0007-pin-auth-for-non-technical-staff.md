# 員工端用 4 位數 PIN 登入,不用帳號密碼或 OAuth

登入方式是「選自己的名字 → 輸入 4 位數 PIN」(bcrypt hash 儲存),不是 email/密碼、magic link 或第三方登入。

**背景**:老闆對 AI/系統零認知,員工是藍領技師、只用手機、平常工作流程全是口頭+紙本記錄。一般網頁應用常見的帳密系統(要記帳號、設密碼、忘記密碼流程)對這群使用者是不必要的摩擦力,PIN 直接對應大家熟悉的提款卡/手機解鎖心智模型,學習成本趨近於零。

**取捨**:犧牲了一些安全嚴謹度(4 位數 PIN 空間遠小於一般密碼)換取可用性,在「共用裝置、非技術使用者、內部小團隊(1 老闆+3-5 員工)」這個情境下判斷是合理的。

**何時要重新考慮**:如果員工規模成長、裝置不再是共用性質,或系統開始處理更敏感的資料,這個安全/可用性的權衡點可能要重新評估,不要預設現在的選擇永遠適用。
