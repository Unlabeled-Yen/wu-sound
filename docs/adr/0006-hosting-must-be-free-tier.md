# Hosting 必須是免費方案,AI API 費用才是老闆願意付的變動成本

系統選 Vercel + Supabase,兩者都跑在免費方案上,不是隨口的技術偏好,是老闆的預算邊界。

**背景**:老闆只願意支付 AI API 的使用量費用(因為那跟實際用量直接掛鉤、看得到成效),不想承擔固定的 hosting 月費。這個約束在專案一開始就定案,直接決定了技術堆疊的選擇——沒有自架伺服器、沒有付費資料庫方案,一切以免費層額度為天花板。

**為什麼值得記錄**:程式碼本身看不出「為什麼用 Supabase 免費層」這個選擇背後有預算約束,單看技術選型會以為只是圖方便。未來如果流量/資料量成長到超過免費層限制(例如 Supabase 專案因為免費層閒置會自動暫停,就曾在 2026-07 發生過一次),不能直接假設「升級付費方案」是可以自己決定的選項,要先跟老闆確認預算共識有沒有變。
