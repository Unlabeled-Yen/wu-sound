# 第一步規格 v1 — 聲學規劃分區與桌機導覽修復(2026-08-03)

## 為什麼

兩個計算器(`/tools/spl-calculator`、`/tools/array-designer`)都已經做好、能跑,但**老闆在電腦上完全到不了**。

桌機側欄(`BossShell.tsx:189` 的 `hidden lg:flex`)只渲染 `SECTIONS` + `SETTINGS_SECTION`,清單是:總覽 / 財務 / 報價系統 / 案件管理 / 現場 / 標案 / 設定。`/boss/more` **只存在於手機底部五格頁籤**(`BossShell.tsx:103`,外層 `lg:hidden`)。計算器唯一的入口在 `/boss/more` 的〈工具〉群組裡,所以桌機使用者只能靠背網址進去。

而老闆是這套系統裡唯一使用電腦的人(員工只用手機)。等於這兩個工具對主要使用者形同未上線。

### 盤點:桌機到底漏了什麼

把 `/boss/more` 的群組逐項對照桌機側欄:

| `/boss/more` 群組 | 項目 | 桌機側欄有嗎 |
|---|---|---|
| 財務 | 薪資結算、帳務管理 | ✅ 有 |
| 報價系統 | 標配套組、價目表 | ✅ 有 |
| 案件管理 | 設備庫存、專案 | ✅ 有 |
| 現場 | 打卡 | ✅ 有 |
| 標案 | 標案監測 | ✅ 有 |
| **工具** | **SPL 預算計算器、陣列設計器** | ❌ **只有這組漏掉** |
| 設定 | 使用者管理 | ✅ 有 |

結論:桌機唯一構不到的就是〈工具〉。所以**只要把工具搬進側欄,桌機的導覽缺口就完全補齊**,不需要為了它另外把「更多」整頁塞進桌機側欄。

## 核心設計

### 開一級區「聲學規劃」,排在「報價系統」之前

不是為了版面,是對應他們自己的業務動線:**訪談 → 聲學規劃 → 報價 → 排程 → 施工**。「聲學規劃」是雇主自己的詞、自己的階段,而目前系統沒有任何位置對應它。

三個理由:

1. **對得上真實瓶頸**。intake Q3 原話是卡在「規劃設計、選用設備」(快則一天、慢則兩週),不是卡在填報價單。計算器正是這一段的工具。
2. **順序即流程**。排在報價之前,side nav 由上而下讀就是他的工作順序。
3. **待補的電學計算有現成的家**。喇叭瓦數×場地公式(仍在 `docs/open-questions.md` 等雇主提供)日後直接掛進這一區,不用再找地方塞。

### 具體改動

**`web/app/boss/_shell/BossShell.tsx`**

在 `SECTIONS` 陣列中,於「報價系統」項目**之前**插入:

```
{
  key: 'acoustic',
  label: '聲學規劃',
  icon: <（新增圖示,見下）/>,
  items: [
    { href: '/tools/spl-calculator', label: 'SPL 預算計算器' },
    { href: '/tools/array-designer',  label: '陣列設計器' },
  ],
}
```

配套:

- **圖示**:比照現有 section 圖示的線條粗細與尺寸風格新增一枚(建議語意:喇叭擴散/聲波弧線)。不得沿用既有圖示造成兩區同圖。
- **`findActiveSection`**(`BossShell.tsx:110-117`):現行比對邏輯以 `pathname` 前綴計分,`/tools/*` 不在任何 section 下時會落回 `SECTIONS[0]`(總覽)。加入本區後需驗證停在 `/tools/array-designer` 時側欄正確高亮「聲學規劃」。
- **`PREFETCH_ROUTES`**(`BossShell.tsx:17`):評估是否納入兩條 `/tools/*`。陣列設計器頁面較重,建議**不預抓**,避免拖慢一般導覽;SPL 計算器可納入。
- **`MOBILE_TITLES`**:新增 `/tools/spl-calculator`、`/tools/array-designer` 兩筆標題,讓手機版頁首不空白。
- **手機底部五格維持不動**。五格已滿且都是高頻動作,聲學規劃屬低頻高專注任務,留在「更多」是正確的。

**`web/app/tools/layout.tsx`**

目前「← 返回」寫死回 `/boss/more`(老闆)或 `/staff/settings`(員工)。老闆在桌機由側欄進入後,返回鍵把他丟到一個桌機側欄沒有的頁面,是斷路。

處理方式:老闆的返回目標改為 `/boss`(總覽),或改用瀏覽器歷史返回。員工維持 `/staff/settings` 不變。

**`web/app/boss/more/page.tsx`**

〈工具〉群組**保留**。手機版仍需要這個入口,兩邊並存不衝突。

## 驗收條件

| ID | 條件 | 方式 |
|---|---|---|
| N-01 | 桌機側欄出現「聲學規劃」,位置在「報價系統」上方 | browser |
| N-02 | 點兩個項目都能正確進入,不 404、不 500 | browser |
| N-03 | 停在 `/tools/*` 時側欄高亮「聲學規劃」,不是「總覽」 | browser |
| N-04 | 老闆在桌機從側欄進計算器後,按「← 返回」不會落到桌機構不到的頁 | browser |
| N-05 | 手機版底部五格不變,「更多 → 工具」仍可進入 | browser(手機尺寸) |
| N-06 | 員工帳號側欄**不出現**此區(工具頁本身仍允許員工進) | browser |
| N-07 | `npx tsc --noEmit` 全過 | auto |

## 不做

- 不把「更多」整頁加進桌機側欄。上表已證明只有〈工具〉漏掉,補這一組就夠。
- 不動手機底部五格。
- 不在這一步碰計算器內部功能(陣列設計器的 5 分頁補完另有 `docs/array-designer/spec-v1.md`)。
- 不做權限調整。計算器目前老闆與員工皆可進,維持現狀。
